# Domain Entities - Unit 2 (IaC/Terraform Module)

## Entity Relational Framework
This document explicitly structures the Data taxonomy generated by Unit 1 that Unit 2 (Terraform) configures inside the AWS Data Catalog. 

### 1. `raw_zone` Abstraction
- **Definition**: S3 origin layer. Unparsed, immutable boundary for bulk transactions matching standard CSV & Parquet files.
- **Attributes**: `layer-region-account-typeofbucket` prefix structure. Extrinsic isolation enforced.

### 2. `curated_zone` Abstraction
- **Definition**: AWS Glue indexed catalog boundary holding strongly formatted Parquet/Iceberg metrics.

### 3. Business Taxonomy Identifiers (LF-Tags)
- **`PiiStatus`**: Defines Data Sensitivity (Values: `Confidential`, `None`).
  - Attached structurally to the `users` table via Terraform logic on the backend.
  - Controls mask filtering (Column-Level Security mapping constraints).

- **`DataGeography`**: Isolates physical zones (Values: `LATAM`, `Global`).
  - Maps securely onto rows validating that `LatamAnalyst` roles observe strict access scopes.

### 4. Logical Interaction Constructs
- **Role Entities**:
  - `DataAdmin`: Maximum oversight. Unmatched access mapping all logical tags safely.
  - `FinancialAnalyst`: Broad numerical access but filtered out from explicitly tagged `Confidential` string values.
  - `LatamAnalyst`: Bound exclusively down into specific table fragments labeled under `DataGeography: LATAM`. Disconnected from remaining global rows dynamically.
